# Свадебный сайт

Сайт-приглашение на свадьбу Алексея и Анастасии.

Проект доступен по адресу: https://alexeyanastasia2026.ru

## О проекте

Одностраничный сайт на React, TypeScript и Vite. На странице собраны основные детали свадебного дня: дата, история пары, регистрация, венчание, банкет, план праздника и обратный отсчет.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Предпросмотр production-сборки

```bash
npm run preview
```
